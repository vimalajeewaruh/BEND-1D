# ChordBeating


## Overview

The **ChordBeating** signal sums three nearby or related tones beneath a smooth audio envelope, producing interference and a slowly varying beat pattern.

## Mathematical Definition

## Mathematical Definition

Define the smooth step

```math
s(x;c,w)=\left[1+e^{-(x-c)/w}\right]^{-1}.
```

Define the smooth tone envelope

```math
E(x)=s(x;c_1,w_1)-s(x;c_2,w_2).
```

Define the multitone component

```math
C(x)=
\sum_{k=1}^{K}
A_k\sin(2\pi f_kx+\delta_k).
```

The signal is

```math
f(x)=E(x)C(x).
```

The component amplitudes, frequencies, and phase shifts are

```math
\mathbf{A}=(0.42,\,0.39,\,0.23),
```

```math
\mathbf{f}=(27,\,29,\,41),
```

```math
\boldsymbol{\delta}=(0,\,0.2,\,-0.4).
```

## Morphological Characteristics

| Property | Description |
|---|---|
| Primary family | Multitone oscillation with beating |
| Tone frequencies | Components at frequencies $\mathbf{f}$ |
| Beating | Primarily generated by interference between the nearby frequencies 27 and 29 |
| Envelope | Smooth onset near $c_1$ and release near $c_2$ |
| Main challenge | Retaining carriers and their low-frequency interference pattern |

## Parameters

| Parameter | Meaning | Default |
|---|---|---:|
| $K$ | Number of tone components | 3 |
| $c_1$ | Envelope onset location | 0.10 |
| $w_1$ | Envelope onset width | 0.030 |
| $c_2$ | Envelope release location | 0.90 |
| $w_2$ | Envelope release width | 0.040 |
| $\mathbf{A}$ | Component amplitudes | $(0.42,\,0.39,\,0.23)$ |
| $\mathbf{f}$ | Component frequencies | $(27,\,29,\,41)$ |
| $\boldsymbol{\delta}$ | Component phase shifts | $(0,\,0.2,\,-0.4)$ |
