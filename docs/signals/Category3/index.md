# BEND-1D Category 3

Category 3 contains application-oriented test functions **TF027–TF042**. The collection emphasizes recurrent and quasi-periodic structure, pathological onset, modulation, pulse trains, intermittent high-frequency activity, damped resonances, sparse impulses, and multiscale propagation effects.

Except for the optional empirical plethysmography trace, these signals are deterministic toy surrogates. They reproduce qualitative measurement features but are not mechanistic simulators.
