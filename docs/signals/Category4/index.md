# BEND-1D Category 4

Category 4 contains measurement-science test functions **TF043–TF058**. These deterministic surrogates represent physical, biological, environmental, and production processes observed through instruments.

The collection includes slow drift, periodic production error, spectral shoulders, maintenance resets, drought depressions, seismic arrivals, oscillatory tremor, isolated extreme events, hysteresis, accelerating burst activity, and overlapping analytical peaks.
