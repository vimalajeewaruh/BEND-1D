# BEND-1D Category 4

This folder contains the GitHub Pages documentation for measurement-science signals **TF043–TF058**.

## Repository placement

Upload this folder to:

```text
docs/signals/Category4/
```

Upload the corresponding PNG files to:

```text
docs/assets/images/
```

Each page therefore uses an image path such as:

```markdown
![StampShadeRun signal](../../assets/images/TF043_StampShadeRun.png)
```

Add this link to `docs/signals/index.md`:

```markdown
[Browse Category 4 Signals](Category4/)
```

The expected image filenames are listed in `index.md`.
