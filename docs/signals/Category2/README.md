# BEND-1D Category 2

This folder contains the Markdown pages for signals **TF017–TF026**.

## Where to place the files

Upload this entire folder to:

```text
docs/Category2/
```

Upload the signal images to:

```text
docs/assets/images/
```

The expected image filenames are:

```text
TF017_Klatno.png
TF018_Cantilever.png
TF019_WaterHammer.png
TF020_ThermalRunaway.png
TF021_Diffraction.png
TF022_Titration.png
TF023_RabiChirp.png
TF024_MuscleTwitch.png
TF025_Platinum5Y.png
TF026_FlashCrash.png
```

Add the following link to `docs/index.md`:

```markdown
[Browse Category 2 Signals](Category2/)
```

If linking from `docs/signals/index.md`, use:

```markdown
[Browse Category 2 Signals](../Category2/)
```

GitHub Pages will use `Category2/index.md` as the landing page for the folder.
