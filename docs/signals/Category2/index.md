# Category 2

Category 2 contains application-oriented test functions. These signals combine dominant low-frequency structure with weaker local features, oscillations, slope defects, transients, or structural changes. All native functions are defined for $0\leq x\leq1$.

| ID | Signal |  Primary morphology |
|---|---|---|
| TF017 | [Klatno](TF017_Klatno.md) |  Localized smooth transition and weak oscillations |
| TF018 | [Cantilever](TF018_Cantilever.md) |  Multimode structure and slope defect |
| TF019 | [WaterHammer](TF019_WaterHammer.md) |  Steep front and damped resonance |
| TF020 | [ThermalRunaway](TF020_ThermalRunaway.md) |  Accelerating trend, instability, and quench |
| TF021 | [Diffraction](TF021_Diffraction.md) |  Central peak, fringes, and satellite |
| TF022 | [Titration](TF022_Titration.md) |  Unequal transitions and weak shoulder |
| TF023 | [RabiChirp](TF023_RabiChirp.md) |  Chirp with decreasing amplitude |
| TF024 | [MuscleTwitch](TF024_MuscleTwitch.md) |  Irregular overlapping causal pulses |
| TF025 | [Platinum5Y](TF025_Platinum5Y.md) |  Empirical multiscale market structure |
| TF026 | [FlashCrash](TF026_FlashCrash.md) |  Structural break, rebound, and transient burst |
