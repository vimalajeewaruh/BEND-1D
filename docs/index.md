# Signal Library

A reproducible library of one-dimensional test signals representing
different smoothness, oscillation, discontinuity, localization, and
singularity structures.

[Browse Signals](signals/) |
[View the Source Code](https://github.com/vimalajeewaruh/BEND-1D)

## About the Library

This library contains ten one-dimensional test signals representing
different morphological characteristics. It is designed to support
reproducible research in signal processing, wavelet analysis, denoising,
feature extraction, and machine learning.

## Main Features

- Ten reproducible test signals
- Mathematical definitions
- MATLAB and Python implementations
- Adjustable signal lengths and parameters
- Optional noise generation
- References and source information
- Visual comparison of signal morphologies

## Signal Families

The current library includes signals representing:

- Smooth structures
- Oscillatory structures
- Chirps
- Discontinuities
- Localized peaks
- Transient events
- Singularities
- Piecewise-smooth structures
- Composite morphologies
